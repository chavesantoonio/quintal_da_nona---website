# Kids Play & Learn

Leia e Siga as instruções do arquivo .MD
Crie um site institucional mas para conversão, design animado e design pedagógico, o frontend é mais importante que qualquer outra coisa, adicione fotos de crianças e também crie uma seção de "o quintal na mídia" onde mostra onde fomos citados, vou preencher depois. 

Coloque fotos de crianças ao decorrer do website para conseguirmos demonstrar o preview à dona. Izabel.

Animações de Fade-in, icons svg profissionais de bibliotecas publicas, 100% mobile first. Whatsapp flutuante no canto direito para contato com "etapas de qualificação" e mensagem de "Traga seu filho para brincar e aprender conosco" e por ai vai...

Passe um balance completo no site depois de pronto e dai entregue
